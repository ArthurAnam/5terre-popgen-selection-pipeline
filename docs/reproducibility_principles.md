# Reproducibility principles

This workflow follows general best practices for scientific computing:

- version control for all manually created files;
- workflow automation through Snakemake;
- separation between raw data, intermediate files, and reproducible outputs;
- centralized parameter configuration;
- documentation of design choices and analytical rationale;
- incremental development and testing.

These principles are inspired by established best practices in scientific computing (Wilson et al., 2014).
